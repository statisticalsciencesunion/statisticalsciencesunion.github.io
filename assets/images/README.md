# Images

Drop site images here:

- `logo.svg` — the SSU mark (a logo file)
- `og-image.png` — 1200x630 social share image
- `team/` — folder for headshots, ideally 800x800 square JPEG/WebP
- `events/` — folder for event photos

Recommended formats:
- Photos: WebP or compressed JPEG
- Logos, icons: SVG
- Social/OG images: PNG at 1200x630
